# 📈 Monitor de Cotações em Tempo Real

Automação desenvolvida em Python para consulta e registro contínuo do valor do Dólar (USD) e Euro (EUR) em relação ao Real (BRL).

## 🚀 Funcionalidades

- **Consulta em tempo real:** Conexão direta com API de economia/cotações.
- **Registro histórico:** Salvamento automático das cotações em formato `.csv` estruturado.
- **Execução contínua:** Loop autônomo com intervalo de atualização personalizável.

## 🛠️ Tecnologias Utilizadas

- **Python 3**
- **Requests** (Requisições HTTP)
- **CSV & Datetime** (Manipulação e persistência de dados)
- **Termux / Linux** (Ambiente de execução)
